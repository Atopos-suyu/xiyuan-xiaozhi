# 免费部署方案对比（2025 现状）

> 目标：**零成本**把后端跑起来、国内可访问。以下方案按推荐度排序。

## 方案 A：本机运行 + 内网穿透（最快速，0 元）

把后端跑在自己的电脑上，用 cpolar/ngrok 生成公网地址。

| 项 | 说明 |
|---|---|
| 成本 | 0 元（cpolar 免费隧道） |
| 步骤 | ① 本机启动后端 → ② cpolar http 8000 → ③ 得到公网 URL → ④ 填入前端 |
| 优点 | 立即能用，数据不出国，可现场演示 |
| 缺点 | 电脑关机服务即停；免费隧道域名会变（付费版固定）；并发有限 |
| 适合 | 先让新生/老师试用、内部演示 |

**立即体验**（我现在就能帮您启动）：
```bash
cd xiyuan-xiaozhi/backend
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 方案 B：阿里云函数计算（免费额度，国内最快）

| 项 | 说明 |
|---|---|
| 成本 | 每月免费额度：100 万次调用 + 40 万 GB·秒，本项目用量远低于此 |
| 前提 | 阿里云账号 + 实名认证（免费） |
| 步骤 | 容器镜像部署（我已备好 Dockerfile）→ 配环境变量 → 绑定默认公网域名 |
| 优点 | 国内访问快、免备案、免服务器 |
| 缺点 | 需要我帮您改造为函数计算部署格式（s.yaml），冷启动 10-60s |
| 适合 | 正式给新生长期使用 |

## 方案 C：腾讯云 CloudBase 云托管（免费额度，国内快）

| 项 | 说明 |
|---|---|
| 成本 | 有免费额度的试用计划（云托管按量，新用户有体验金） |
| 前提 | 腾讯云账号 + 实名认证 |
| 步骤 | 云托管导入 GitHub 仓库 → 自动构建 Dockerfile → 配环境变量 → 域名访问 |
| 优点 | 界面化操作简单，与微信生态（公众号/小程序）天然衔接 |
| 缺点 | 免费体验金有限，长期使用需付费（月几元到几十元） |
| 适合 | 后续接公众号/小程序时的正式方案 |

## 方案 D：Hugging Face Spaces（免费，国外访问慢）

| 项 | 说明 |
|---|---|
| 成本 | 免费 CPU Space（2vCPU/16GB），模型本来就是 HF 生态 |
| 优点 | 部署极简，免费额度充足 |
| 缺点 | huggingface.co 国内访问不稳定，只适合海外或自用 |
| 适合 | 演示、开源项目展示 |

## 方案 E：学校资源 / 学生优惠（最正规）

- 学校信息中心/实验室服务器：最稳定，需向学校申请
- **GitHub Student Developer Pack**（在校学生免费申请）：含 Azure for Students（100 美元/年）、DigitalOcean（200 美元/年）等，可作为正规部署资源
