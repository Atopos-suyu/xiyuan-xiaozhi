# 合规说明（上线前必读）

本文档汇总在中国大陆面向公众提供本服务涉及的主要合规要点。**本文件不构成法律意见，正式上线前请咨询学校法务/信息中心。**

## 1. 生成式 AI 服务备案

依据《生成式人工智能服务管理暂行办法》（2023年8月15日施行）：

- 面向境内公众提供生成式 AI 服务，提供者需要履行**大模型备案/算法备案**等手续。
- **本项目推荐的合规路径**：通过**已备案的模型服务商**（DeepSeek 等）的公开 API 接入。模型能力由服务商提供，服务商已履行其备案义务；我方作为"应用开发者"使用其 API，须遵守服务商的服务条款与内容管理要求。
- 如果学校信息中心要求，可进一步咨询属地网信办关于"具有舆论属性或社会动员能力"的互联网信息服务安全评估要求。

## 2. 内容安全

- 已内置基础安全过滤（`backend/app/safety.py`）：隐私信息拦截、边界引导、违规内容拒绝。
- **正式上线建议**：接入云厂商内容安全服务（阿里云/腾讯云文本审核）作为第二道防线，拦截涉政、违禁、涉黄暴内容。
- 保留对话日志（含时间、脱敏后的内容）便于审计；日志仅限授权人员查看。

## 3. 个人信息保护（《个人信息保护法》）

- 系统**不采集**用户姓名、手机号等身份信息；`session_id` 为随机生成，不关联真实身份。
- 已在提示词与前端界面明确：不索取身份证号、银行卡、验证码等敏感信息。
- 若需留存日志用于质量评估，建议对日志做脱敏处理，并明确告知用户（如页面隐私声明）。

## 4. 知识产权与素材来源

- 知识库仅收录**无锡学院官方公开网页/文档**，抓取时遵守目标站点 robots 协议并限速（脚本已内置 1 秒间隔）。
- 若使用《新生入学手册》等版权材料，需获得学校相关部门授权。
- 项目名"锡院小智"及无锡学院相关标识的使用，需学校官方书面授权。

## 5. 平台规则

- **微信公众号**：接入对话服务需遵守微信平台规则（如消息管理、用户隐私政策、类目要求）。
- **网页/小程序**：小程序审核对"问答/教育类"有资质要求，需提前确认主体资质。

## 6. 免责声明（建议展示）

> 锡院小智的回答基于无锡学院官方公开信息生成，仅供参考；涉及具体日期、流程、政策的信息，请以学校官方最新通知为准。
